# Fuentes autoalojadas

## Atkinson Hyperlegible

Estos archivos `.woff2` son la tipografía **Atkinson Hyperlegible**, diseñada
por el **Braille Institute of America** para maximizar la legibilidad.

- **Autor:** Braille Institute of America, Inc.
- **Sitio:** https://www.brailleinstitute.org/freefont/
- **Licencia:** SIL Open Font License 1.1 (OFL-1.1)

Se incluyen autoalojados para que la instalación **no dependa de servicios
externos** (Google Fonts u otros CDN), de acuerdo con el principio de
autodespliegue del proyecto.
